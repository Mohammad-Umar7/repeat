# REPEAT

**Show it once. Then just press Tab.**

REPEAT is an AI agent that lives inside the browser where work already happens. Demonstrate a multi-step workflow once (read a bug email, create a Jira ticket, post to Slack) and it becomes a reusable automation. The next time the same situation appears, a ghost cursor pre-fills the whole workflow in grey. Tab to accept, Esc to dismiss. Every run is on a timeline with one undo slider that reverts everything across every app.
